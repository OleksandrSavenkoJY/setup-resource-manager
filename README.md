# Setup Resource Manager

MVP for managing setup inventory and generating prompts for diagram creation.

## Tech stack
- Backend: FastAPI
- Database: PostgreSQL
- Frontend: Next.js
- Deployment: Docker Compose

## Features
- Create setup records
- List setups
- View setup details
- Update setups
- Delete setups
- Generate prompt text from stored setup data
